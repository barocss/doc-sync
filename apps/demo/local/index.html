DOC SYNC / LOCAL

Local document editors

Each editor has its own document. Type, select text, and use Undo or Redo.

Independent documentsShared document

Memory only. Refresh restores the sample. Reset restores one editor.

Use ⌘Z or Ctrl+Z to undo. Use ⇧⌘Z, Ctrl+Shift+Z, or Ctrl+Y to redo.

Insert prefix adds “Local ” at the start and keeps the current selection.
